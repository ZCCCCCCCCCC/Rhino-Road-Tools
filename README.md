# Rhino 道路设计脚本集

基于 RhinoCommon API 的道路/公路基础设施设计自动化脚本集合。

## 工具列表

| 脚本 | 功能 |
|------|------|
| `三维道路标线生成器.rhproj` | 三维道路标线生成（Rhino 项目文件） |
| `基于三维线的虚实标线创建.py` | 沿三维路线生成虚/实标线曲面，带 Eto.Forms 参数面板 |
| `路灯行道树一键放样.py` | 沿道路曲线批量布置路灯和行道树 |
| `沿线阵列.py` | 沿三维曲线参数化阵列排布对象 |
| `RH单独缩放.py` | 按各自包围盒中心独立缩放多个对象 |

## 使用

在 Rhino 中通过 `RunPythonScript` 加载对应 `.py` 文件运行。
